1. OVERVIEW
--------------------------------------------------------------------
The three apps (server / webapp / admin) of the old "EdHippo" clone
have been rebranded and rebuilt into "Education Portal" — a school
discovery + admission-guidance platform for Dubai.

  - Brand name .... Education Portal (Dubai)
  - Colours ....... Royal Blue #1e4fa3  +  Gold #d4af37
  - Backend ....... NestJS + MongoDB (separate DB) — Redis removed
  - Live API ...... https://school-portal-backend-wt5b.onrender.com
                    (verified LIVE, MongoDB connected)

All "EdHippo" branding, text and API data has been removed from the
UI across all three apps.
